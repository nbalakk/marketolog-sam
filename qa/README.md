# Проверка редизайна

18.10.2026: 368 успешных проверок в headless Edge. Viewport: 320, 360, 390, 457, 768, 1024, 1374, 1440 px. Ошибок JavaScript и отсутствующих ресурсов нет.

Проверены все 27 состояний демонстрации на каждом экране, отсутствие горизонтального переполнения, первый CTA в видимой области и неизменная высота панели. Дополнительно: меню, стрелки/Home/End в табах, свайпы, диалог с восстановлением фокуса, FAQ, копирование, ссылки и локальные якоря, правовые документы, reduced-motion и основные элементы без JavaScript.

Счётчики на основном домене проверены через перехват запросов: нет загрузки до согласия, одно событие на CTA, прекращение после отзыва согласия. На предпросмотре исходная аналитика не работает. События внешним счётчикам при проверке не отправлялись.

Повторить: `pip install playwright`, `playwright install chromium`, `python qa/check_site.py`. Для установленного браузера задайте `SAM_BROWSER_PATH`. `SAM_DEV_TOOLS` позволяет указать каталог с Python-зависимостями. JSON-результат и скриншоты проверки исключены из Git.
