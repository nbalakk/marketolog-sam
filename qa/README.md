# Проверка сайта

Проверено 18.10.2026: 87 успешных проверок, 8 viewport (320, 360, 390, 457, 768, 860, 1024, 1440 px), без горизонтального переполнения и ошибок JavaScript.
Проверены ссылки/якоря, диалог и Escape, меню, clipboard feedback, основные элементы без JavaScript, работа аналитики только после согласия и её остановка после отзыва. Внешние счётчики при проверке перехватывались: события им не отправлялись.

Для повторения: `pip install playwright==1.64.0`, `playwright install chromium`, `python qa/check_site.py`.
Можно задать `SAM_BROWSER_PATH` для установленного браузера. Результат пишется в results.json, изображения — в screenshots/; они исключены из Git.
