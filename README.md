# Сэм — редизайн сайта после UX-аудита

Публичный предпросмотр: https://nbalakk.github.io/marketolog-sam/

Согласованный эскиз реализован в коде: мягкий жёлтый, синий акцент, интерактивные примеры и умеренные анимации. Проверка визуального соответствия и поведения — [design-qa.md](design-qa.md).

## Структура
- `original/` — опубликованный HTML, CSS, JS, документы и публичные ресурсы, сохранённые до исправлений.
- `source-manifest.json` — происхождение и контрольные суммы скачанных ресурсов. Серверный код и код бота не извлекались.
- `dist/` — готовые статические файлы для GitHub Pages или любого статического хостинга. Зависимостей и сборки нет.
- `docs/AUDIT-STATUS.md` — статус каждого замечания и ограничения.
- `docs/QUESTIONS.md` — вопросы владельцу перед окончательным выпуском.
- `qa/` — проверки поведения и адаптивности.

## Локальный запуск
В папке проекта: `python -m http.server 8000 --directory dist`, затем открыть http://localhost:8000.

## Публикация
GitHub Pages публикует только `dist/` через workflow. Оригиналы, вопросы и материалы проверки в публичный сайт не попадают.
Предпросмотр исключён из поисковой индексации. Перед переносом на основной домен замените robots.txt на разрешающий индексацию, установите `index, follow` в index.html и обновите абсолютные OG-адреса на домен выпуска.

## Что заполнить после ответа владельца
`dist/site-config.js` содержит только публичные настройки. В `pricing` добавьте подтверждённые `freeDescription`, `plans` (name, price, period, limits), `renewalDescription` и затем `verified: true`. Без полного набора условий цены не рисуются.
Инструкцию отмены и сведения о работе бота дополните в `dist/index.html`. Публичные юридические документы сохранены без смысловых изменений и нуждаются в проверке владельцем.

## Аналитика
Счётчики исходного сайта сохранены, но запускаются только после явного согласия и только на `marketolog-sam.ru` / `www.marketolog-sam.ru`. На GitHub Pages и localhost они не отправляют события. Параметр placement различает кнопки сайта; Исходный start=landing сохранён для совместимости с ботом. Команда открытия тарифов сохранена исходной. Произвольные новые start-параметры не используются без проверки поддержки ботом.

## Права
Код и публичные материалы исходного сайта сохранены по поручению пользователя с разрешения владельца. Открытость репозитория не предоставляет лицензию на чужие материалы; отдельная open-source лицензия не назначена.

## Текущий дизайн — 19.10.2026

Светлая digital-страница: минеральный мятно-голубой градиент, хвойный акцент и локальный Onest. Три примера задач переключаются кнопками и клавиатурой. Запрос можно скопировать для Telegram; тексты честно обозначены редакционными образцами. Настоящее меню бота раскрывается отдельно. Согласие на аналитику расположено внизу страницы и доступно через настройки.

Дизайн-система: [DESIGN.md](DESIGN.md). Финальная проверка: [design-qa.md](design-qa.md). [Desktop](qa/calm/desktop.png), [мобильный первый экран](qa/calm/mobile-first.png).

Для проверки установите Python-пакет playwright и его Chromium, затем запустите `python qa/check_site.py`. Можно задать `SAM_BROWSER_PATH` для собственного браузера и `SAM_DEV_TOOLS` для папки зависимостей. Скрипт проверяет 138 условий на десяти ширинах, включая копирование, отказ буфера обмена, меню, dialog, аналитику, документы и настройку уменьшенного движения. Снимки сохраняются в `qa/screenshots/calm/`; публикационные файлы тест не изменяет.

Отдельная работающая версия: https://nbalakk.github.io/marketolog-sam/frontend-design/. Основная мятная версия сохранена для сравнения.

Применён официальный skill `anthropics/skills/skills/frontend-design`: светлый фон, чернильный индиго, локальный Golos Text, крупная типографика и сравнение трёх редакционных подач одного поста. При выборе подачи меняются материал и копируемый запрос; имитации онлайн-генерации нет. Остальные сценарии, настоящие изображения бота, условия, юридические ссылки и выбор аналитики сохранены.

План и его проверка до реализации: `qa/fixtures/frontend-direction.json`. Проверка: `python qa/check_frontend.py` (те же зависимости и переменные окружения, что у основной проверки). 230/230 проверок на десяти ширинах, без ошибок JavaScript и загрузки ресурсов. Основные файлы прежней версии сверяются с сохранёнными хешами. Снимки и результат — `qa/frontend/`; диагностические состояния — `qa/screenshots/frontend/`.


### Авторский моушен в первом экране

Первый экран теперь показывает финальные 15-секундные ролики пользователя: горизонтальный на компьютере, вертикальный на телефоне. Экспорты и постеры скопированы из проекта sam-motion без изменений; исходный Remotion-проект не редактировался. Черновые ролики не публикуются. Происхождение, размеры и контрольные суммы: `qa/fixtures/motion-assets.json`.

Браузер получает только подходящий формат: WebM, либо MP4 при отсутствии поддержки WebM. Беззвучное видео проигрывается один раз; доступны пауза и повтор. При уходе за пределы экрана или скрытии вкладки оно останавливается. После окончания показывается содержательный постер. Уменьшенное движение и экономия трафика отключают автоматическую загрузку видео; запуск остаётся доступен по нажатию. Без JavaScript остаются постер и настоящая кнопка Telegram. При ошибке загрузки доступны постер, повторная попытка и прямая ссылка MP4. Сюжет также можно прочитать текстом.

Ролик честно обозначен демонстрацией, а не записью ответа бота. Кнопка открытия бота находится вне видео и работает независимо от воспроизведения. Существующие примеры, выбор тона, копирование, FAQ и условия сохранены.

`python qa/check_motion.py`: 44/44 проверки, включая реальное декодирование WebM и H264 в браузере, выбор мобильного файла, ручное управление, уменьшенное движение, экономию трафика, блокировку автозапуска, отказ загрузки и отключённый JavaScript. `python qa/check_frontend.py`: 230/230 проверок на десяти ширинах; основной сайт, документы и настройки сверены с контрольными суммами. Выбранные снимки и результаты: `qa/frontend/`.

Прежняя предметная сцена керамики заменена роликом; её изображение и описание происхождения сохранены как материалы предыдущей итерации.
