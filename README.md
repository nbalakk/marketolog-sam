# Сэм — сайт после UX-аудита

Публичный предпросмотр: https://nbalakk.github.io/marketolog-sam/

## Структура
- `original/` — опубликованный HTML, CSS, JS, документы и публичные ресурсы, сохранённые до исправлений.
- `source-manifest.json` — происхождение и контрольные суммы скачанных ресурсов. Серверный код и код бота не извлекались.
- `dist/` — готовые статические файлы для GitHub Pages или любого статического хостинга. Зависимостей и сборки нет.
- `docs/AUDIT-STATUS.md` — статус каждого замечания и ограничения.
- `docs/QUESTIONS.md` — вопросы владельцу перед окончательным выпуском.
- `qa/` — проверки поведения и адаптивности.

## Локальный запуск
В папке проекта: `python -m http.server 8000 --directory dist`, затем открыть http://localhost:8000.

## Публикация
GitHub Pages публикует только `dist/` через workflow. Оригиналы, вопросы и материалы проверки в публичный сайт не попадают.
Предпросмотр исключён из поисковой индексации. Перед переносом на основной домен замените robots.txt на разрешающий индексацию, установите `index, follow` в index.html и обновите абсолютные OG-адреса на домен выпуска.

## Что заполнить после ответа владельца
`dist/site-config.js` содержит только публичные настройки. В `pricing` добавьте подтверждённые `freeDescription`, `plans` (name, price, period, limits), `renewalDescription` и затем `verified: true`. Без полного набора условий цены не рисуются.
Инструкцию отмены и сведения о работе бота дополните в `dist/index.html`. Публичные юридические документы сохранены без смысловых изменений и нуждаются в проверке владельцем.

## Аналитика
Счётчики исходного сайта сохранены, но запускаются только после явного согласия и только на `marketolog-sam.ru` / `www.marketolog-sam.ru`. На GitHub Pages и localhost они не отправляют события. Параметр placement различает кнопки сайта; Исходный start=landing сохранён для совместимости с ботом. Команда открытия тарифов сохранена исходной. Произвольные новые start-параметры не используются без проверки поддержки ботом.

## Права
Код и публичные материалы исходного сайта сохранены по поручению пользователя с разрешения владельца. Открытость репозитория не предоставляет лицензию на чужие материалы; отдельная open-source лицензия не назначена.
